# Idea Remixer (`remix`)

_Mirror of the Brand OS playbook, regenerated by the Kit Curator. Don't edit by hand._

- Job: Merges, pivots, duplicates and re-edits ideas into the best version for you.
- Zone: Create · Status: To build · Trust level: L0 · Playbook version: 4
- Last change: Oct 31: version count and types became defaults

## Playbook
- Default: a few versions per idea (often 3), from whatever fits: a framework cut, a long-form segment, footage already on hand, or something new
- Name the series and any keyword for each version
- Trial Lab default: versions differ in the first 3 seconds (a different opening shot, not only new text), optionally in length
- Label versions by hook type so the Analyst can learn which type wins
- Exploration: one version in a set tests something the system isn't sure about yet (see Experiments)
